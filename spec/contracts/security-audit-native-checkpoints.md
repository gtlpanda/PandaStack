Terminal receipt replay remains legal while paused and does not require new-dispatch authority.

Serialize terminal callback commit/publication through the same short boundary so normal own mutations do not create spurious admission pauses. Never hold this boundary while waiting for model/provider execution; this is no second scheduler, lock owner or accounting authority. Check cancellation/deadline while waiting for the boundary.
